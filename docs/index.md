# Wiki de Impressão 3D

Bem-vindo à nossa wiki sobre impressão 3D.

Este material foi desenvolvido para apresentar os conceitos básicos e o fluxo completo da impressão 3D, desde a criação do modelo digital até o pós-processamento da peça final.

## Conteúdo

- [Introdução](introdução.md) - Conceitos básicos e aplicações da impressão 3D
- [Como funciona](como-funciona.md) - O fluxo completo do processo de impressão
- [Modelagem 3D](desenho-3d.md) - Ferramentas e formatos para criação de modelos
- [Fatiamento](fatiador.md) - Processo de preparação do modelo para impressão
- [G-code](gcode.md) - Linguagem de comandos para impressoras 3D
- [Materiais (filamentos)](filamentos.md) - Tipos de materiais e suas características
- [Pós-processamento](pos-impressao.md) - Finalização e acabamento das peças

## 🎯 Objetivo

Esta wiki serve como guia completo para iniciantes e intermediários no mundo da impressão 3D, fornecendo informações práticas e técnicas para cada etapa do processo.

## 📚 Como usar

Siga as páginas na ordem sugerida para entender o fluxo completo, ou navegue diretamente para o tópico de seu interesse.
