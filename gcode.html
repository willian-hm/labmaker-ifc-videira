G-code

Entenda como a impressora 3D interpreta comandos, controla movimentos, temperaturas e executa cada camada da impressão.

O que é?

O G-code é uma linguagem utilizada para controlar máquinas CNC e impressoras 3D. Ele define todos os movimentos, temperaturas e ações executadas durante a impressão.

Estrutura básica

G21 ; Unidades em milímetros
G90 ; Coordenadas absolutas
M82 ; Extrusor em modo absoluto
G28 ; Home de todos os eixos
G1 Z0.2 ; Levantar bico
G1 X0 Y0 ; Ir para origem

Calibração e teste

M106 S255 ; Ventilador máximo
G1 X100 Y100 F3000 ; Movimento rápido
G1 X0 Y0 F3000 ; Retornar
M107 ; Desligar ventilador

Impressão principal

M190 S60 ; Esperar base
M109 T0 S210 ; Esperar extrusor
G1 X0 Y0 F3000 ; Posicionar
G1 Z0.3 F900 ; Ajustar altura
G92 E0 ; Resetar extrusor
G1 E10 F300 ; Extruir material

Comandos finais

M104 S0 ; Desligar extrusor
M140 S0 ; Desligar base
M107 ; Ventilador OFF
G1 Z10 ; Levantar bico
M84 ; Desligar motores

Configurações por material

PLA

  • Extrusor: 190°C a 210°C
  • Base: 50°C a 60°C
  • Boa ventilação
  • Fácil de imprimir

PETG

  • Extrusor: 220°C a 240°C
  • Base: 70°C a 80°C
  • Maior resistência
  • Menos ventilação

ABS

  • Extrusor: 240°C a 260°C
  • Base: 90°C a 110°C
  • Necessita ambiente fechado
  • Maior resistência térmica

Otimização

  • Reduzir movimentos desnecessários
  • Melhorar trajetórias
  • Controlar velocidade em detalhes
  • Otimizar retrações
  • Evitar desperdício de material
